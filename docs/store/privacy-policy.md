# プライバシーポリシー — GazePause

最終更新日: 2026年8月1日

「GazePause」(以下「本拡張機能」)は、Google Chrome の拡張機能です。本ポリシーは、本拡張機能がどのような情報を扱うか、またその情報をどのように取り扱うかを説明するものです。

## 1. 本拡張機能の機能概要

本拡張機能は、ユーザーのWebカメラ映像から顔の向きをリアルタイムに解析し、ユーザーが画面(テレビ・ディスプレイ)から視線を外したことを一定時間検出すると、再生中のYouTubeまたはAmazon Prime Videoの動画を自動的に一時停止します。視線が画面に戻った際は、設定に応じて自動的に再生を再開します。

## 2. 取り扱う情報とその扱い

### 2.1 カメラ映像・顔のランドマーク(顔の特徴点)データ

- 本拡張機能は、ユーザーが明示的にカメラの使用を許可した場合にのみ、Webカメラの映像を取得します(オプトイン方式。詳細は「4. カメラアクセスの許可について」参照)。
- カメラ映像は、拡張機能内部の非表示ページ(offscreen document)で、MediaPipe Face Landmarker(顔の特徴点を検出するライブラリ)を用いてブラウザ内(ローカル)で処理されます。
- この処理により得られる顔の向き(角度)の情報は、「画面を見ている/見ていない」という一時的な状態としてのみ、拡張機能のメモリ上で扱われます。
- **カメラ映像、映像から抽出した顔のランドマークデータ、および算出した顔の向きの情報は、いかなる外部サーバーにも送信されません。** また、これらのデータはディスク等に保存されることもなく、映像フレームも保持されません。
- 本拡張機能のソースコードには、外部サーバーへ通信を行う fetch / XMLHttpRequest / WebSocket 等の処理は一切実装されておらず、この点はコードレビューのプロセスにおいても都度確認しています。

### 2.2 拡張機能の設定情報

本拡張機能は、以下のユーザー設定のみを保存します。

- 拡張機能の有効/無効
- 顔の向きを判定する角度のしきい値
- 状態確定までの継続フレーム数(判定感度)
- 視線が戻った際に自動で再生を再開するかどうか

これらの設定は `chrome.storage.sync` に保存されます。これは Google Chrome が提供する、ユーザー自身の Google アカウントに同期される保存領域であり、**本拡張機能の開発者が保存内容にアクセスすることはできません。** 開発者のサーバー等、開発者が管理する外部の場所にこれらの設定が送信されることもありません。

## 3. 第三者への情報共有

本拡張機能は、上記のいずれの情報(カメラ映像、顔のランドマークデータ、拡張機能の設定情報)についても、**第三者への提供・共有・販売を一切行いません。** 本拡張機能には、広告配信、アクセス解析、その他のトラッキング目的の仕組みは組み込まれていません。

## 4. カメラアクセスの許可について

カメラへのアクセスは、Webブラウザの標準API(`getUserMedia()`)を通じて行われます。拡張機能の設定(オプション)ページにあるボタンをユーザーが押した際にのみ、Chrome標準の許可ダイアログが表示されます。この許可は明示的なオプトインであり、ユーザーはいつでも Chrome の設定からカメラへのアクセス許可を取り消すことができます。

## 5. 権限について

本拡張機能が要求する Chrome 拡張機能の権限は、機能の実現に必要な最小限のものに限定しています。

| 権限 | 用途 |
|---|---|
| `offscreen` | カメラ映像の解析処理をバックグラウンドで行うための非表示ページを作成するため |
| `storage` | 上記「2.2 拡張機能の設定情報」を保存するため |
| ホスト権限(`youtube.com` / `primevideo.com` / `amazon.co.jp`) | 対象サイトで再生中の動画を一時停止・再生するため |

## 6. Chrome ウェブストア Limited Use 要件への準拠

本拡張機能によるユーザーデータの取得・使用・共有は、Chrome ウェブストア Developer Program Policies の [Limited Use 要件](https://developer.chrome.com/docs/webstore/program-policies/limited-use)に準拠しています。すなわち、取得したデータは本拡張機能が提供する「視線に応じた動画の自動一時停止」というユーザー向け機能の実現にのみ使用し、広告目的での利用や、関連のない用途への転用、第三者への販売は一切行っていません。

## 7. データの削除

拡張機能の設定情報(2.2節)は、Chromeの拡張機能管理画面から本拡張機能をアンインストールすることで削除されます。カメラ映像・顔のランドマークデータはそもそも保存されないため、削除すべき保存データは存在しません。

## 8. 本ポリシーの変更

本ポリシーの内容は、法令の変更や本拡張機能の機能追加に伴い、予告なく変更されることがあります。重要な変更を行った場合は、本ページの「最終更新日」を更新します。
