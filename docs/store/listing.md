## 詳細説明(description)

```
GazePauseは、動画を見ながらよそ見をしてしまったときに、自動で再生を一時停止してくれるChrome拡張機能です。

■ こんな方におすすめ
・動画を見ながら他の作業をしていて、気づいたら話の内容を見逃していた
・離席したのに動画が再生され続けていて、戻ってきたら巻き戻す羽目になった
・「一時停止を押し忘れる」という小さなストレスをなくしたい

■ 主な機能
・YouTube / Amazon Prime Videoに対応し、視聴中の動画を自動で一時停止
・画面に視線が戻ったら自動で再生を再開(設定でON/OFFを切り替え可能)
・判定の感度(顔の向きのしきい値・反応までの継続時間)を自分の環境に合わせて調整可能
・オプションページのボタンから、必要なときだけカメラの利用を許可するシンプルな操作

■ プライバシーを最優先に設計
GazePauseは、プライバシーを何より重視して設計されています。
・顔の向きの解析処理は、すべて拡張機能内(お使いの端末上)で完結します。カメラ映像や顔の特徴点データを外部のサーバーへ送信する通信は一切行いません。
・映像そのものも保存されず、「画面を見ている/見ていない」という一時的な状態としてのみ扱われます。
・保存されるのはユーザーご自身の設定(有効/無効、判定感度、自動再開の可否)のみで、Chromeの同期ストレージ(chrome.storage.sync)に保存されます。開発者を含む第三者がこの内容を閲覧することはできません。
・カメラへのアクセスは、オプションページのボタンを押したときにのみ許可を求める、明示的なオプトイン方式です。

■ シンプルな目的にこだわっています
GazePauseが行うことはただひとつ、「視線に応じて動画の再生を自動で制御すること」です。それ以外の機能(広告表示、アクセス解析、無関係なデータ収集など)は一切含まれていません。

動画視聴中の「うっかり見逃し」「うっかり離席」を、視線だけでスマートに解決したい方はぜひお試しください。
```

## single purpose ポリシーへの補足メモ

Chromeウェブストアの single purpose ポリシー審査を意識し、以下の点を掲載文・Developer Dashboardの
該当欄で一貫させること。

- 単一の目的: 「ユーザーの視線(顔の向き)に応じて、対象サイト(YouTube / Prime Video)の動画再生を
  自動的に一時停止・再開する」の一文に集約できるようにする
- 権限(`offscreen` / `storage` / host_permissions)は、いずれもこの単一目的の実現に直結する用途
  以外に説明しない(例: 「ついでに便利な○○機能も」といった訴求を追加しない)
- Developer Dashboardの「このアイテムの目的」欄にも、上記と同じ一文をベースに記入する
